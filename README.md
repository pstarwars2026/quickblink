# QuickBlink

How fast are you, really? QuickBlink is a reaction time trainer for iPhone and iPad with five game modes (Classic, Hold & Release, Decoy, Choice, Sound), a Daily Challenge, frame-accurate timing, badges and Game Center leaderboards. Free, with no ads, accounts or tracking.

**Version 2.0 is now available** on the App Store as a free update for iPhone and iPad. Requires iOS or iPadOS 18.0 or later. Released October 5, 2026.
